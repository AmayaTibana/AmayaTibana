## 🏗️ Featured project

**[Modern Lakehouse](https://github.com/AmayaTibana/modern-lakehouse)**: a batch pipeline from public APIs to a Snowflake star schema.

- Ingests PokéAPI and Weather.gov data into Amazon S3
- Spark transforms raw data into curated Parquet
- Python loads a star schema into Snowflake
- Airflow orchestrates the run, with data quality checks and CI
